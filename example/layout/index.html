窗口正文里怎么排

每张卡片是一扇真窗口,外观全部来自库的 .window / .window-header / .window-body. 顶上切三档口径,拖一条高度滑杆,就能看见库里今天那条你看不见的规则干了什么, 以及方案要把它换成什么.

现在的问题(白话版)
  1. 库有一条你没写的规则:.window-body > * { flex: 1 1 auto; min-height: 0 }. 正文里的直接子节点一律被拉满,并且可以被压扁.所以"工具条 + 主体 + 底栏"三块会一起按内容比例 分正文 -- 工具条被压扁,底栏被压扁;放两个普通块,它们会各分一半(谁也没声明过).
  2. 窗口正文是 overflow: hidden:装不下的内容不给你滚动条,直接裁掉. 想滚就得自己套一层 overflow: auto,手挂 .ui-scrollbar, 还要沿每一层补 min-height: 0(漏一层就是"滚不动"或"被压扁").
  3. 现有示例里那句 .pane > button { align-self: flex-start } 就是这条规则的反作用: 按钮被拉成整行宽,只好再写一句抵消它.
固定条(工具条 / 底栏):内容多高就该多高 普通块 .ui-fill:吃掉剩余 .ui-scroll-area:显式滚动区 红= 这一档有问题(被压扁 / 被拉高 / 够不到)

库里今天这条(styles/desktop.css,一个字没改)

/* 窗口正文:确定高度 + 裁切都归它 */
.window > .window-body {
    display: flex;
    flex-direction: column;
    flex: 1 1 auto;
    min-height: 0;
    padding: 0;
    overflow: hidden;
}

/* ↓ 通吃:正文里每个直接子节点都被拉满,而且允许被压扁 */
.window-body > * {
    flex: 1 1 auto;
    min-height: 0;
}

方案要换成这条(phase3.css + phase4.css,只作用于本页)

/* Phase 3:三条**显式**拉伸出口,特异度 (0,2,0),
   比库那条 (0,1,0) 高,所以现在就生效 */
.ui-panel-body > :only-child,
.ui-panel-body > .ui-fill,
.ui-panel-body > .ui-scroll-area {
    flex: 1 1 0;          /* basis 0:多个出口均分,不按内容比 */
    min-height: 0;
    min-width: 0;
}
.ui-scroll-area { overflow: auto; }

/* Phase 4:默认不拉伸(与库那条同特异度,靠后加载取胜;
   真正落地时是把库那条删掉,在 widgets.css 写这一条) */
.ui-panel-body > * { flex: 0 0 auto; }

卡片对应方案里的哪一条

① 唯一子节点
   -> :only-child(回归项:三档必须一样)

② 工具条 + 主体 + 底栏
   -> 4.4 第 1 / 3 条:固定条定住,
     溢出只发生在显式滚动区

③ 两个普通块
   -> 4.2 的另一面:溢出被裁

④ 两个 .ui-fill
   -> 4.4 第 1 条 / 决定 D6:均分
